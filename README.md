# 🌍 Country Search

A simple website to search and explore information about countries using **HTML**, **CSS**, and **JavaScript**.

## 🚀 Features

- 🔎 Search for any country by name
- 📄 View details like capital, region, population, and flag
- 🌐 Uses data from a public API (REST Countries)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- [REST Countries API](https://restcountries.com/)
