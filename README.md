

# 🌍 Country Search - https://lucas-souuza.github.io/country-search/

A responsive web application for searching and exploring country information using data from the REST Countries API.

## 📌 Overview

Country Search is a simple and interactive front-end project built with HTML, CSS, and vanilla JavaScript.  
It allows users to search for countries by name and quickly view useful information such as capital, region, population, and flag.

This project was created to practice:
- API consumption with JavaScript
- DOM manipulation
- Responsive interface development
- Real-time search functionality

## ✨ Features

- Search for countries by name
- View country details instantly
- Display key information such as:
  - Capital
  - Region
  - Population
  - Flag
- Responsive and clean user interface
- Integration with a public REST API

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- [REST Countries API](https://restcountries.com/)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/lucas-souuza/country-search.git
```

### 2. Open the project folder

```bash
cd country-search
```

### 3. Run the project

Open the `index.html` file in your browser.
